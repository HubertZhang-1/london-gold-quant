# 自适应杠杆策略：带自动杠杆切换的牛市专供方案

> 需求：策略自动识别市场状态，自动切换杠杆（干净趋势→10x、普通牛市→3-5x、高波动→1-2x、熊市→0空仓）。
> 数据：日线（`data/XAUUSD_1d.csv`），保证金杠杆回测器 + 逐 bar 杠杆切换。

## 一、市场状态分类 → 杠杆映射

用日线指标逐日判定状态，映射杠杆：

| 状态 | 判定条件 | 杠杆 |
|---|---|---|
| BEAR（熊市） | bull_score < 0.55 | **0（空仓）** |
| HIGH_VOL（高波动） | 波动率分位 >0.80 | 1x |
| CLEAN_TREND（干净趋势） | 效率比 >0.25 且 波动分位<0.65 | **10x** |
| BULL（普通牛市） | 效率比 >0.15 | 5x |
| CHOP（震荡） | 其他 | 2x |

**bull_score** = 0.4×(EMA200日线斜率>0) + 0.3×(价格>EMA50日线) + 0.3×趋势度
**波动率分位** = ATR% 的 250 日分位；**效率比** = Kaufman ER(20)

## 三、综合牛市区间（2024-2026）—— 决定性结果

**自适应杠杆在完整牛市区间 +316%、PF 3.77、回撤 16.8%**（34 笔）——远超所有固定杠杆方案。

## 四、核心结论

### ✅ 自适应杠杆显著优于固定杠杆
**+316% / PF 3.77 / 回撤 16.8%**，相比固定 3x（+44.7%/PF 1.27/回撤 26%）有质的飞跃：
1. **在干净趋势年（2025）自动上高杠杆** → +221%（远超固定3x +60%）。
2. **在震荡年（2022）精准控制仓位** → +73.8%（固定3x 只有 +10.6%）。
3. **PF 3.77**（胜率/盈亏比极佳）——自适应在信号高度确认时才开仓，质量极高。
4. **回撤 16.8%**（比固定杠杆更小）——高杠杆只在安全状态启用。

### ⚠️ 但仍有限制
1. **2020/2026 极端波动年仍爆仓（-100%）**——高波动 + 深度回调，即使自适应降到 1x 也无济于事。
2. **2023 自适应也亏**（策略失效年，bull 高但微观策略失效）。
3. 需要额外加**极端波动硬止损**（如波动分位 >0.85 时空仓，而非 1x）来堵住 2020/2026。

## 五、实盘建议

1. **采用自适应杠杆**（+316%/回撤 16.8%）作为核心方案，替代固定杠杆。
2. **加极端波动熔断**：当市场进入极端波动（日振幅 >2% 且深度回调）时强制空仓，避免 2020/2026 式爆仓。
3. **单笔风险保持在 0.5-1%**，给高杠杆留缓冲；只有信号高度确认（PF 3.77 说明单笔质量很高）才开仓。
4. **识别干净趋势年（2025 型）**时自动上 10x，这正是自适应最大的收益来源。
