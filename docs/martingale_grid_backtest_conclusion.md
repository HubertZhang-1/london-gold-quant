# 对冲马丁网格 EA 样本外回测结论（复刻截图策略）

> 策略来源：MT5 实盘截图（STARTTRADER FINANCIAL Live，XAUUSD.c 伦敦金）。
> 回测数据：`data/XAUUSD_5m_2026.csv`（HistData 下载，2026-01-01 至 2026-08-28，共 46,709 根 5m K 线）。

## 一、复刻的合约与策略规则

**合约（已用截图联立验证）**：1 lot = 100 盎司，盈亏 = (平仓-开仓)×手数×100，无额外手续费。

**策略逻辑（`london_gold/martingale_grid.py`）**：
1. **单边马丁主仓**：EMA(60) 判断趋势方向，主仓沿趋势开仓；价格逆主仓方向每走一步（`grid_step = ATR(14)×mult`）加一档，
   手数阶梯 **0.3 → 0.7 → 1.0 → 1.5 → 2.0 → 3.0 ...**
2. **均价回正即平**：主仓浮盈 ≥ `ATR×tp_atr`（截图中单笔赚 30-70 美元 ≈ 1-2 美元波幅）时整篮子平仓。
3. **反向对冲**：主仓浮亏 ≥ `ATR×hedge_atr` 时开反向对冲单锁亏；主仓平仓时对冲一并平仓。
4. **成本**：点差 $0.35 + 单边滑点 $0.10 + 佣金 $0.10/oz。
5. **风控熔断**：单日亏损 3%、最大回撤 30%、爆仓。

## 二、回测结果（默认参数 grid=1.0 / tp=1.0 / layers=6）

| 指标 | 值 |
|---|---|
| 期末净值 | $173,804（+73.8%） |
| 交易数 | 5,902 笔（主仓 3,242 / 对冲 2,660） |
| 胜率 | **50.9%** |
| 平均盈利 / 亏损 | +$135.71 / -$115.65 |
| 盈亏因子 | 1.22 |
| **最大回撤** | **29.7%（触发熔断）** |
| 基准（买入持有） | +3.0% |

## 三、参数扫描（grid × tp × layers，100 组）

```
grid=0.8:  PF 1.32  回撤 27-30%  max_drawdown
grid=1.0:  PF 1.20  回撤 27-30%  max_drawdown
grid=1.2:  PF 1.07  回撤 29%     max_drawdown
grid=1.5:  PF 0.79  日亏熔断（亏损）
```

**关键观察**：
- 网格步长越小（0.8-1.0），PF 略 >1 但**所有参数都在 27-30% 回撤处触发 max_drawdown 熔断**。
- 步长放大到 1.5 时，**策略直接亏损**（PF 0.79），交易量从几千骤降到 200+ 笔。
- 胜率始终在 **51% 附近**，而非截图展示的 **77%**。

## 四、与截图画像的对比（核心结论）

| 维度 | 截图展示 | 本回测（2026 真实 5m） | 判断 |
|---|---|---|---|
| 胜率 | 77% | 51% | **截图可信度存疑** |
| 盈亏比 | 亏<盈（PF 1.98） | 亏 > 盈（PF 1.22） | 更符合马丁本质 |
| 单日收益 | 显示小幅稳定盈利 | 高回撤、触发熔断 | 截图是**事后挑选的有利片段** |
| 盈亏因子 | 1.98 | 1.22 | 截图可能有**无成本/无滑点**假设 |

**核心结论**：
1. **这套策略在真实 5m 数据上无法稳定复现截图的高胜率**。截图里的 77% 胜率和漂亮曲线，要么是**事后挑选**的有利时段，要么其回测**豁免了点差/滑点/持仓成本**（截图单笔 30-70 美元 / 0.3 手 ≈ 1-2 美元波幅，恰好等于无成本时的网格毛利润）。
2. **马丁网格的本质在真实数据上暴露无遗**：高胜率 + 负盈亏比，靠**补仓摊平 + 一次回本**扛利润。几乎所有参数都在 **27-30% 回撤**处熔断——这是马丁策略的**数学必然**（遇单边趋势补仓满格后仍逆势 → 深回撤/爆仓）。
3. **没有择时/地域优势**。参数扫描里找不到能在"样本内赚钱且回撤可控"的稳定区间，步长稍变就从 +70% 变到亏损，说明收益对参数极度敏感 = **过拟合**，不是稳健 alpha。

## 五、风险量化警示

- 单边趋势（黄金日波动 1%-2%，5m 上更常见）时，主仓从 0.3 补到 6 层（累计 8.8 手），任何一次没能回正就被熔断。
- **最大回撤 29.7%** 是模型自带的 30% 熔断线——真实 EA 若**没有**这层熔断（截图策略 nam e"对冲加仓"通常硬扛），回撤会更深，直接威胁本金。
- 结论：**不建议照搬实盘**。截图是"好看的曲线"，而样本外回测显示它是在**用尾部熔断风险换取 51% 的高频小赢**。

## 六、如何改进（如果要做自己的版本）

1. **去掉马丁翻倍**，改等手网格（固定 0.3 或 0.5），牺牲胜率换可控回撤。
2. **加硬止损**（单笔/单篮子），不用"均价回正"这一必然扛单的离场方式。
3. **用 ATR 动态定步长**（目前已用），但把 `max_layers` 降为 3-4，控制暴露。
4. **做滚动样本外验证**（逐月滚动），确认 PF>1.2 且回撤<15% 才考虑实盘。
