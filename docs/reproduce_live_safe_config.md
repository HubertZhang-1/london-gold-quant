# 复现实盘安全配置建议（双边对冲网格马丁）

> 目标：用户要**复现这套双边对冲网格马丁策略自己实盘跑**，但无法查看原 EA 后台参数（朋友圈图，无输入参数面板），且担心爆仓。
> 核心原则：**复现它的盈利逻辑，但自建安全边界 —— 因为截图无证据显示它带自动日亏熔断。**
> 结论：**熔断线（日亏/回撤）才是真正的风控阀，马丁层数不是。** 收紧日亏线即可把单边逆风月最坏亏损控制住，同时几乎不影响顺风月收益。

## 一、关键量化定律

用 `martingale_grid.py` 在"顺风月(2026-08, 单边+9.4%)"和"构造单边下跌月(-5%)"两种环境扫描：

| 配置 | 顺风月 | 单边下跌月 | 结论 |
|---|---|---|---|
| layers=3, dl=0.03 | +256% | **-3.8%（熔断）** | 层数3几乎无影响 |
| layers=6, dl=0.03 | +268% | **-3.8%（熔断）** | |
| **layers=6, dl=0.02** | +268% | **-2.8%（熔断）** | **收紧日亏线 → 逆风月亏更少** |

**定律**：
1. **无论马丁层数设 3 还是 6，只要日亏熔断触发，单边下跌月都只亏 -3.8%（或 -2.8%）就停机**。
2. **控制风险的不是"层数上限"，而是"日亏熔断线"** —— 收紧它（2%）能把最坏逆风亏从 -3.8% 降到 -2.8%；放宽它（/去掉）才是真正会爆仓的风险。
3. **顺风月几乎不受影响**（+256%~268%），因为顺风时不触发日亏熔断。

## 二、推荐实盘安全配置

```python
from london_gold.martingale_grid import MartingaleConfig, run_martingale_backtest

cfg = MartingaleConfig(
    initial_balance_usc=100_000.0,
    stop_loss_atr=0.0,          # 忠实原版：无单笔止损（靠熔断兜底）
    use_trend_filter=True,      # 主仓沿趋势
    max_layers=4,               # 马丁层数（顺风仍 +262%）
    daily_loss_pct=0.02,        # ★ 日亏 2% 熔断（最坏 -2.8%）
    max_drawdown_pct=0.20,      # ★ 总回撤 20% 熔断
)
res = run_martingale_backtest(df, cfg)
```

### 验证结果（推荐配置）
| 环境 | 表现 |
|---|---|
| 顺风月（2026-08，+9.4%） | **+262%**，胜率 47%，PF 1.24 |
| 单边下跌月（构造 -5%） | **-2.8%**（日亏熔断停机，不爆仓） |

## 三、为什么这样设（对实盘最重要）

1. **必须自己设熔断**：截图没有任何自动熔断证据，只有 `一键锁仓 / 平仓` 这类**人工**按钮。若靠人工锁仓，8.5 手深仓 + 单边趋势 = 会爆仓。
2. **日亏 2% 是你的安全阀**：最坏哪天 -2% 全平停机，保住本金；这是"能长期活下去"的关键。
3. **层数不是重点**：max_layers 3→6 对顺风/逆风影响都不大，因为它**先被日亏熔断兜住**了。无需纠结层数。
4. **代价（诚实）**：单边逆风月会快速认亏（-2.8%）——它**无法像顺风月那样 +268% 回补**。这是"用顺风大赚 + 逆风小亏换不爆仓"的取舍。

## 四、如果原 EA 真的带熔断怎么办

如果将来你拿到原 EA 参数、发现它**确实带**日亏熔断（如 daily_loss=3%）：
- 那你复现时**保持它的熔断**即可（风险已被兜底）；
- 但仍建议**不高于 5%**（太松会放大逆风亏损）。
