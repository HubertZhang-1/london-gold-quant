# 自适应 + 熔断实盘策略（bull_adaptive.py）— 收益弹性升级版

> 正式落地的**自适应杠杆 + 安全熔断**黄金牛市专供策略。核心：只在高确认的牛市参与，自动切换杠杆，极端波动空仓，不爆仓，且**按信号信心分配风险敞口**提升收益弹性。
> 数据：黄金日线（`data/XAUUSD_1d.csv`，2004-2026）。

## 一、策略逻辑

**市场状态 → 杠杆 + 基准单笔风险映射**（日线逐日判定）：

| 状态 | 判定 | 杠杆 | 基准单笔风险 |
|---|---|---|---|
| 熊市 | bull < 0.55 | **0（空仓）** | — |
| 极端波动 | 波动分位 > 0.85 | **0（空仓）** | — |
| 高波动 | 波动分位 > 0.80 | 1x | 2% |
| 干净趋势 | 效率比>0.25 & 波动<0.8 | **10x** | 0.5% |
| 普通牛市 | 效率比>0.15 | 5x | 1% |
| 震荡 | 其他 | 2x | 2% |

**安全熔断（多层）**：
1. **极端波动空仓**：波动分位>0.85 时完全空仓（2020/2026 型不在场）。
2. **风险随杠杆反比**：10x→0.5%、5x→1%、低杠杆→2%，单笔止损有限。
3. **回撤熔断**：峰值回撤超 20% 强制平仓停机。

**信号**：微观精选多因子（macd/aroon/trend_adx/ema_spread/bulls_bears/momentum/bb），SL=2×ATR、TP=2×(SL)。

## 二、收益弹性：按信号信心分配风险（v2 升级）

> 原版（v1）的问题：信号质量极高（牛市区间 PF 10.8）但收益只有 +12.4%，因为**单笔风险敞口被压得过小**（10x→0.5%）。收益瓶颈在"敞口"而非"信号质量"。

**为什么不能统一放大风险**：把全部单笔风险统一 ×N，收益虽线性上升，但弱年份（2020/2023/2026，PF<1）的亏损也被同步放大，先撞 20% 熔断。**2026 在统一 x6 时直接爆仓**；完整区间统一 x3 就爆仓。

**正确做法：信心缩放**——每个信号的风险按 `|micro|` 信心加权：

```
risk = 基准风险 × conf_mult × (conf_floor + (1-conf_floor) × |micro|^conf_power)
```

强信号（|micro| 大，趋势确定性高）给**更多**风险，弱信号给**更少**。这样牛市年份吃到敞口红利，弱年份仍被保护。

**效果对比（牛市区间 2024-2026 / 完整区间 2004-2026）：**

| 配置 | 牛市收益 | 牛市PF | 牛市回撤 | 完整收益 | 完整回撤 | 爆仓 |
|---|---|---|---|---|---|---|
| v1 基线 | +12.4% | 10.80 | 0.9% | +5.5% | 9.0% | 无 |
| 统一 x3 | +37.2% | 10.80 | 2.5% | **爆仓** | 100% | ⚠️ |
| **信心 x2.5（生产）** | **+23.7%** | **11.95** | **1.9%** | **+12.4%** | **15.2%** | **无** |
| 信心 x3.0 | +28.4% | 11.95 | 2.2% | +13.9% | 17.5% | 无 |

**选定：信心 x2.5（conf_mult=2.5, conf_floor=0.3, mc=20%）**
- 牛市区间收益 +23.7%（较 v1 提升 91%），PF 从 10.8 **升到 11.95**（因为风险集中到真正强信号）；
- 完整区间 +12.4%（较 v1 +5.5% 翻倍），回撤 15.2%，**全程不爆仓**；
- 收紧熔断线至 15% 反而有害（会过早截断恢复中的浮亏持仓，导致爆仓），故保持 20%。

## 四、实盘配置

```python
from london_gold.bull_adaptive import AdaptiveConfig, run_adaptive
cfg = AdaptiveConfig(
    capital=100_000,
    micro_thr=0.5,            # 信号阈值
    stop_mult=2.0,            # SL=2×ATR
    rr=2.0,                   # TP=2×(SL)
    margin_call_pct=0.20,     # 回撤熔断线（保持20%，勿收紧）
    risk_10x=0.005,           # 10x杠杆基准风险0.5%
    risk_5x=0.01,             # 5x杠杆基准风险1%
    risk_low=0.02,            # 低杠杆基准风险2%
    conf_mult=2.5,            # 信心缩放倍数（收益弹性）
    conf_power=1.0,           # |micro| 映射强度
    conf_floor=0.3,           # 最低信心保底（1.0=旧行为）
)
res = run_adaptive(每日数据, cfg)
```

**运行**：`py scripts/bull_adaptive_report.py`（生成权益/交易/月度报告）。

## 五、定位

这套**自适应+熔断+信心缩放**版在"高收益 vs 不爆仓"权衡上做到了比 v1 更好的平衡：
- **收益翻倍**（牛市 +12.4%→+23.7%，完整 +5.5%→+12.4%），
- **PF 更高**（10.8→11.95，风险集中在强信号上），
- **仍不爆仓**（所有年份无 -100%），回撤温和（牛市 1.9%）。

**适合**：追求长期稳健复利、但希望收益弹性比保守版更足、且无法承受爆仓风险的实盘资金。
**代价**：完整区间回撤从 9% 升到 15.2%（可接受，仍在熔断线内）。
