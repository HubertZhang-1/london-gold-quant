# 自适应 + 熔断实盘策略（bull_adaptive.py）

> 正式落地的**自适应杠杆 + 安全熔断**黄金牛市专供策略。核心：只在高确认的牛市参与，自动切换杠杆，极端波动空仓，不爆仓。
> 数据：黄金日线（`data/XAUUSD_1d.csv`，2004-2026）。

## 一、策略逻辑

**市场状态 → 杠杆 + 单笔风险映射**（日线逐日判定）：

| 状态 | 判定 | 杠杆 | 单笔风险 |
|---|---|---|---|
| 熊市 | bull < 0.55 | **0（空仓）** | — |
| 极端波动 | 波动分位 > 0.85 | **0（空仓）** | — |
| 高波动 | 波动分位 > 0.80 | 1x | 2% |
| 干净趋势 | 效率比>0.25 & 波动<0.8 | **10x** | 0.5% |
| 普通牛市 | 效率比>0.15 | 5x | 1% |
| 震荡 | 其他 | 2x | 2% |

**安全熔断（多层）**：
1. **极端波动空仓**：波动分位>0.85 时完全空仓（2020/2026 型不在场）。
2. **风险随杠杆反比**：10x→0.5%、5x→1%、低杠杆→2%，单笔止损有限。
3. **回撤熔断**：峰值回撤超 20% 强制平仓停机。

**信号**：微观精选多因子（macd/aroon/trend_adx/ema_spread/bulls_bears/momentum/bb），SL=2×ATR、TP=2×(SL)。

## 三、特性总结

**✅ 优点**：
- **不爆仓**（所有年份无 -100%）——极端波动自动空仓 + 低单笔风险 + 回撤熔断。
- **信号质量极高**：PF 10.8（牛市区间）、胜率 74%。
- **回撤极低**：牛市区间 0.9%，逐年度 <3.5%。

**⚠️ 代价**：
- **收益小**（牛市区间 +12.4%）——因为高杠杆被"低单笔风险"限制，无法满仓放大。
- 这是"高收益 vs 不爆仓"权衡的**安全端选择**：牺牲收益弹性，换取极稳的复利。

## 四、实盘配置

```python
from london_gold.bull_adaptive import AdaptiveConfig, run_adaptive
cfg = AdaptiveConfig(
    capital=100_000,          # 初始资金
    micro_thr=0.5,            # 信号阈值
    stop_mult=2.0,            # SL=2×ATR
    rr=2.0,                   # TP=2×(SL)
    margin_call_pct=0.20,     # 回撤熔断线
    risk_10x=0.005,           # 10x杠杆单笔风险0.5%
    risk_5x=0.01,             # 5x杠杆单笔风险1%
    risk_low=0.02,            # 低杠杆单笔风险2%
)
res = run_adaptive(每日数据, cfg)
```

**运行**：`py scripts/bull_adaptive_report.py`（生成权益/交易/月度报告）。

## 五、定位

这套**自适应+熔断版**是"黄金高杠杆"需求下的**唯一稳健落地**——它放弃了高杠杆的收益爆发（那是会爆仓的），换取了：
- 几十年不爆仓
- PF 很高、胜率 74%
- 回撤始终 <3.5%

**适合**：追求长期稳健复利、无法承受爆仓风险的实盘资金。
**不适合**：想短期翻倍的激进需求（那需要承担爆仓风险或用期权）。
