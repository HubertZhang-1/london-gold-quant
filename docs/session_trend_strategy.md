# 亚洲盘 vs 欧洲盘(伦敦) 趋势分析与延续策略

> 需求：查询亚洲盘和欧洲盘伦敦金线性回归趋势是否一致，结合亚洲盘波动趋势进行策略写入。
> 数据：2026-07 + 08 真实 1m 数据（58,737 根，43 个交易日）。
> 时段（沿用项目 `intraday_strategies_v3.SESSIONS_UTC`）：亚洲盘 = UTC 0-7 点；欧洲盘/伦敦 = UTC 7-13 点。

## 一、两盘趋势一致性（线性回归 OLS 斜率）

对每个交易日，分别在亚洲盘窗口、伦敦盘窗口对 1m 收盘价做 OLS 线性回归求斜率，再比较：

| 指标 | 数值 | 含义 |
|---|---|---|
| **亚洲/伦敦斜率同号率** | 55.8% | 略高于随机(50%)，但**远未一致** |
| **斜率相关系数 r** | **0.250** | 弱正相关 |
| **区间收益相关系数 r** | 0.234 | 弱正相关 |

**结论：亚洲盘与欧洲盘(伦敦) 的趋势只是弱相关，约 46% 的日子背离，不能简单认为"同涨同跌"。**

## 二、分组统计（最有价值的发现）

按两盘方向是否一致分组，看欧盘平均收益：

| 分组 | 天数 | 欧盘平均收益 | 判断 |
|---|---|---|---|
| **双涨**（亚盘涨+欧盘涨） | 16 天 | **+0.83%** | ✅ 顺势延续有正期望 |
| 双跌（亚盘跌+欧盘跌） | 8 天 | -0.31% | |
| **背离**（两盘方向相反） | 19 天 | **-0.16%** | ❌ 无延续性、偏亏 |

**核心 edge**：当亚洲盘给出明确方向、且欧盘同向延续时，欧盘趋势有把握（+0.83%）；当两盘背离时，欧盘缺乏延续（-0.16%）。

## 三、亚洲盘波动特征

| | 均值 | 中位 | 最高 | 最低 |
|---|---|---|---|---|
| 亚洲盘日内 std | 9.32 | 7.86 | 33.54 | **3.14** |
| 欧洲盘日内 std | 14.80 | 11.84 | 50.48 | 5.45 |

- 欧盘波动明显大于亚盘（约 1.6 倍）；
- 亚洲盘有时极窄（3.14）——**死水/无行情**，这类时段欧盘不该参与。

## 四、写入的策略：亚洲盘→欧盘延续（`session_follow.py`）

**逻辑**：用亚洲盘的方向 + 波动做"欧盘延续"信号。
1. **方向明确**：亚洲盘区间净变动 `|持仓开盘→收盘| ≥ min_asia_ret_pct(0.15%)`；
2. **非死水**：亚洲盘日内波动 `vol ≥ min_vol(6)`；
3. **顺势**：欧盘开盘（UTC 7）顺着亚洲盘方向开单；
4. **离场**：欧盘收盘（UTC 13）平仓，或 ATR×亚洲盘vol 的止损/止盈（`stop_mult=2, rr=2`）；
5. **风控**：单笔 1% 风险、手数 cap 1。

## 五、回测结果（最佳配置）

**min_ret=0.15%、min_vol=6、stop=2、rr=2：**

| 指标 | 数值 |
|---|---|
| **总收益** | **+12.7%**（净利 +$12,711） |
| **盈亏因子** | **2.63** |
| **胜率** | **62%** |
| 交易数 | 24 笔（做多13 / 做空11） |
| 做多胜率 | **77%** |
| 做空胜率 | 45% |

**离场原因分布**：`session_end`（持到欧盘收盘）82% 胜率；`tp`（止盈）100%；`stop` 0%（风控）。

## 六、诚实结论

1. **验证了假设**：亚洲盘与欧盘趋势弱正相关（r=0.25），且"亚洲盘给方向 + 欧盘顺势延续"是**正期望**（PF 2.6、胜率 62%）。
2. **最大亮点**：**做多胜率 77% vs 做空 45%** —— 黄金系统性长期上行，顺势做多的延续性远强于做空。这再次印证"黄金多头"特性。
3. **必须诚实指出的局限**：
   - **样本仅 24 笔、43 天**，不足以证明长期稳健；
   - **单笔盈亏偏大**（avgW+1366/avgL-910）——亚洲盘低波动放大了手数，需进一步收紧风控；
   - **背离日(46%)是负贡献**——本策略通过"方向明确 + 波动过滤"已尽量规避，但无法完全消除。
4. **定位**：这是一个**依赖日内时段延续性的轻仓策略**，适合在主策略之外作为"时段增强"；不建议独立全仓实盘（样本太短）。
