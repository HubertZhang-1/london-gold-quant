# 实盘EA 改造：牛市单向版（bull_grid.py）

> 需求：把 MT5 截图那套实盘EA（STARTTRADER FINANCIAL Live 8 · XAUUSD.c 伦敦金）改造成**牛市单向版**——只做多、牛市参与、熊市空仓，去掉网格/对冲/双向耗损。
> 原则：**只做牛市，熊市不参与**。回测窗口：2024-2026（与之前一致），并用完整区间校验不爆仓。

## 一、为什么要改造（原版的问题）

原版是**对冲马丁网格**（`martingale_grid.py` 复刻）。项目此前用真实 5m 数据复刻回测已证明：
- 胜率 51%（截图宣称 77%），PF 1.22（截图 1.98）——**截图是事后挑的有利片段 + 可能豁免了成本**；
- **所有参数都在 27-30% 回撤处触发熔断**，遇到单边趋势补仓满格仍逆势 → 深回撤/爆仓；
- 双向随时进出，**和多空双向、牛市门控完全无关**，违背"只做牛市"原则。

## 二、改造内容（bull_grid.py）

相对原版的关键改变：

| 维度 | 原版（马丁网格） | 改造版（牛市单向版） |
|---|---|---|
| 方向 | 多空双向 | **只做多** |
| 入场 | EMA(60) 趋势开主仓 | **bull 分 ≥ 阈值 + 收阳** 才做多 |
| 熊市 | 仍参与 | **bull < 阈值 → 完全空仓**，不限时 |
| 手数 | 马丁阶梯 0.3→0.7→1.0→1.5→... 翻倍 | **固定手数 或 风险预算定仓** |
| 离场 | 均价回正才平（必然扛单） | **硬止损（ATR×stop_mult）+ 止盈（RR）+ 时间止损** |
| 对冲 | 反向对冲锁亏硬扛 | **去除** |
| 爆仓尾部 | 有（补仓满格逆势） | **无**（单笔风险受限） |

**bull 分**：复用自适应策略的 `_bull_score`——EMA 斜率 + 价格 vs EMA + trend_regime，综合成 [0,1]，≥0.55 视为牛市。

**风险预算定仓**（关键改进）：`风险%` = 单笔最大亏损占账户比例，手数 = `风险金额 / (止损距离 × 100盎司)`。这让不同波动时的手数合理、止损真正起效、回撤可控。

## 四、与原版/激进版的对比

| 策略 | 2024-26 收益 | 2024-26 回撤 | 完整区间结果 | 符合"只做牛市" |
|---|---|---|---|---|
| 原版马丁网格 | （复刻 +73.8% 但 30% 回撤爆仓） | 29.7% | **会爆仓** | ❌ |
| 自适应 x15 | +101.2% | 6.2% | **-100% 爆仓** | ⚠️ 部分 |
| **牛市单向版** | **+74.5%** | **5.8%** | **+116.8% 不爆仓** | ✅ |

**结论**：
1. **牛市单向版是最符合你原则、且稳健不爆仓的形态**：牛市中高频小赚（PF 4.11、胜率 77%），熊市/震荡基本空仓不参与，完整区间 +116.8% 都不爆仓。
2. 相比自适应 x15（牛市更强但非牛市就爆仓），**牛市单向版牺牲了一点牛市爆发力，却换来"跨市场不爆仓"的安全**——这正是"只做牛市、熊市不参与"的落地。
3. **它保留了原版EA的高频小赚特征，但去掉了马丁爆仓尾部和双向耗损**，是真正的"改造后"策略，而非原样照搬。
