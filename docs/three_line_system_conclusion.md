# 三线合成系统：CFTC 持仓 + 宏观 + 微观量价接入

> 数据：XAUUSD 1h 连续（2004-2026）、CFTC COT 持仓（2018-2026，452 周）、宏观（DXY/VIX/10Y，2017-2026）。
> 目标：把 CFTC COT（中观择时）与宏观数据（实际利率/美元/VIX）接入现有引擎，与微观多因子+regime 一起，构建三线合成系统。

## 一、三层信号架构

```
宏观层（macro_direction_score）  ：实际利率(10Y代理)、美元DXY、VIX危机门控 → 长周期方向分 [-1,1]
中观层（cot_factors 五因子投票）  ：CFTC COMEX持仓 → 短周期择时分 [-1,1]
微观层（factor_library 多因子）  ：macd/aroon/trend_adx/ema_spread/bulls_bears/momentum/bb + regime过滤
        ↓  三线独立、加权合成
合成方向/仓位（composite score → 方向 + ATR sizing）
```

## 三、CFTC 五因子投票（复刻国信证券框架）

从 COMEX 黄金 COT 五类参与者（ProdMerc 产业、Swap 掉期、MgrMny 管理基金、OthRepo 其他报告商、NonRept 散户）构建 5 个独立因子：
1. 投机多头占比（管理基金情绪）
2. 产业空头占比（套保广度）
3. 空头集中度（产业+掉期短占比）
4. 产业净持仓（套保恐慌/底部信号）
5. 其他报告商多头变化（半机构动量）

`cot_factors.py` 实现 `compute_cot_factors` + `cot_5factor_vote_factors` + `cot_timing_score`，投票 ≥2/5 做多、≤-2/5 做空。

## 四、宏观方向分

`macro_factors.py` 的 `macro_direction_score`：基于研究回归（实际利率↑→金价↓、美元↑→金价↓、VIX仅危机时↑利多），
用 DXY/10Y/VIX 的变化正交化后合成 [-1,1] 宏观方向分。

## 五、三线合成引擎

`gold_system.py` 的 `build_three_line_frame`：微观 + 宏观 + 中观 → 加权合成（默认 macro=0.3, cot=1.0, micro=1.0），
叠加 `trend_regime`（趋势度）门控，输出方向 + ATR 止损/止盈。

## 六、权重调优结论（关键）

| 配置 | 2018-20（低波动）| 2024-25（牛市）| 2026 | PF |
|---|---|---|---|---|
| macroW=0, cotW=1.0, thr=0.25 | +4.0% (DD53%) | +63.3% | +45.2% | **1.75** |
| **macroW=0.3, cotW=1.0, thr=0.15** | **+28.2% (DD31%)** | +44.3% | +55.8% | 1.57 |
| macroW=0.6, cotW=1.0, thr=0.15 | -15.7% | +37.0% | +44.0% | 1.50 |

**核心发现**：
- **宏观层权重宜低（0-0.3）**：宏观层是"方向风标/背景确认"，独立做信号会压制牛市多头收益；CFTC + 微观已捕获足够择时信息。
- **最优平衡**：`macroW=0.3, cotW=1.0, thr=0.15` —— 2018-20 转正(+28%/回撤31%)、2024-25 保留 +44%、2026 +55.8%。

## 八、核心结论

**三线合成系统的真正价值是"穿越市场状态"而非"最大化收益"**：

1. ✅ **救回了低波动/横盘市**：2018 转正、2019/2021/2023 大幅减亏、2020 增强。微观多因子在这类市场原本会亏（2018-23 独立验证 -7.4%），加上 CFTC+宏观层后亏损显著收窄、回撤全面可控。
2. ✅ **回撤全面下降**：三线合成各年最大回撤都更小（如 2018 DD 42%→26%、2020 DD 21%→14%）。
3. ⚠️ **代价是牛市收益减半**（2024/2025 +100% 级 → +20-30%）：CFTC+宏观层在强趋势牛市中偏保守，压低了多头弹性。
4. **与东证多周期合成结论一致**：合成后夏普提升、回撤下降（17年样本夏普 1.19/1.43 那类），但单看收益未必更大。

**定位**：这套三线合成是**长期复利/回撤可控**的系统——横盘市少亏、牛市稳赚、回撤可控。适合追求稳健、能承受牺牲部分牛市弹性换取穿越能力的情形。

## 九、待改进
