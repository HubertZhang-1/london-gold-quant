## 一、实锤的合约规格

用 6 笔成交联立验证，**1 lot = 100 盎司**，且无额外手续费（或已含在点差内）：

```
盈亏 USD = (平仓价 - 开仓价) × 手数 × 100    （多单）
            (开仓价 - 平仓价) × 手数 × 100    （空单）
```

## 二、策略类型

**异步双向网格 + 马丁格尔加仓对冲**（hedged martingale grid）。核心是"跌了接多、涨了接空+单边加仓摊平成本"，在震荡/回调中靠**摊薄均价 + 对冲锁亏**赚钱。

### 主手法：单边马丁补仓（2026-07-16 那一段最典型）

同向 3 笔多单在下跌中被逐级加仓：

| 层级 | 手数 | 买入价 | 距上一档 | 状态 |
|---:|---:|---:|---:|---|
| L1 | 0.3 | 4035.65 | — | 初始 |
| L2 | 0.7 | 4030.63 | -5.02 | 补仓 ×2.33 |
| L3 | 1.0 | 4024.35 | -6.28 | 补仓 ×1.43 |

均价 = 4028.24，全部在 **4028.66** 一次了结 → 净 +83.40。
- 关键：**L3 手数放大**（0.3→0.7→1.0），只要价格回到均价附近就能盈利出局。
- 补仓间距 ≈ 5-6 美元（ATR 或固定价差），并且**马丁倍数不是严格 ×2**（0.7/1.0 这样取整），是"阶梯放大"而非纯翻倍。

### 配对手法：反向对冲单（hedge）

在 2026-07-16 同时看到 **sell 0.3 开在 4023.99 / 4025.70** 的空单被套（-20、-83）。
- 这是**多空两边都开**的布局：一边是趋势方向做多马丁，另一边开反向单用于**锁定亏损/限制单边风险**。
- 对冲单触发条件疑似：当某方向净持仓亏损达到一定阈值（或价格穿越反向网格线）时开反向单。

## 三、统计画像（22 笔可辨认成交）

| 指标 | 值 |
|---|---|
| 手数分布 | 0.3 手占 91%（基础仓），0.7/1.0 为补仓层 |
| 中位持仓 | ~78 秒；≤90 秒占 50%（大量剥头皮式短单） |
| 胜率 | 77%（短单赢、补仓单偶尔大亏） |
| 平均盈利 | +63.56 |
| 平均亏损 | -109.06（**亏损单远大于盈利单**） |
| 盈亏因子 | 1.98 |
| 单日风格 | 高频小赚 + 偶尔一次大额补仓回本 |

**核心结构**：胜率高但盈亏比 <1（平均亏 > 平均赚）。利润靠**马丁补仓"一次大额回本"**扛起来——这就是马丁策略的典型数学：平时小赚，遇趋势反转靠翻倍补仓，一旦补满仍不回头就爆仓。

## 五、关键风险与结论

1. **这是高胜率+负盈亏比的马丁网格**，收益曲线在震荡市很漂亮，遇**单边大趋势**（尤其黄金动辄 1%-2% 日内波动）极易**补仓满格后仍逆势 → 爆仓/穿仓**。
2. 平均亏损（-109）> 平均盈利（+63）说明**大量浮亏被扛**，靠补仓摊平而非止损纪律。
3. **多品种并行**让单日胜率稳定，但也放大了总敞口——一个品种趋势失控，别的品种对冲不一定能救。
4. 结论：这套策略**不能直接照搬实盘**。它展现了"高频小额 + 马丁回本"能做出好看的盈利曲线，但本质是**用尾部爆仓风险换取高胜率**，和我们项目里之前验证的网格回测脆弱性一致。

- **用 ATR 动态定网格间距**（当前距断约为 5-6 美元，接近 5m ATR 的倍数），不要用固定点差。
