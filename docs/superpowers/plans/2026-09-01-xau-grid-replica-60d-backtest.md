# XAU Grid Replica 60-Day Proxy Backtest Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and run an auditable 60-day, six-scenario proxy backtest for the approved bidirectional ATR grid/hedge strategy on GC=F 5-minute bars with 100,000 USC initial capital.

**Architecture:** Keep the replica isolated from the existing directional London-gold backtesters. A data module normalizes and audits OHLC input, an event-driven engine owns positions/account state and walks either O-H-L-C or O-L-H-C paths, and a reporting/CLI layer runs the 2 path × 3 spread matrix and exports mutually reconcilable artifacts.

**Tech Stack:** Python 3.11, pandas, numpy, requests, unittest, standard-library `dataclasses`, `decimal`, `json`, and `pathlib`.

**Spec:** `docs/superpowers/specs/2026-09-01-xau-grid-replica-backtest-design.md`

## Global Constraints

- This phase is historical proxy testing only; it must not connect to MT5 or submit any order.
- Use Yahoo Finance `GC=F` 5-minute OHLC for the latest available 60-day range and label every result as a COMEX proxy, not broker `XAUUSD.c` evidence.
- Start from 100,000 USC, use `pnl_usc = direction * (exit_fill - entry_fill) * lots * 100`, and simulate spread values 0.35, 0.525, and 0.70 price units.
- Use previous-completed-bar Wilder ATR14 only and `clamp(ATR * 0.35, 0.60, 2.50)` for each bar's fixed grid step.
- Start Buy 0.02 and Sell 0.02 simultaneously, add 0.01 lots per layer, and cap each direction at nine grid layers.
- Direction target is `max(100 USC, balance * 0.0005)`; global target is `max(250 USC, balance * 0.0012)` with 30-second restart cooldown.
- Hedge only when floating loss is at least 1.5% of equity and absolute net lots are at least 30% of gross lots; hedge 60% of net lots, rounded down to 0.01.
- Stop additions at 8% UTC-day realized loss; liquidate and permanently stop at 20% peak-equity drawdown or non-positive balance/equity.
- Do not add dependencies, modify existing directional engine behavior, or touch unrelated dirty files.
- Do not commit; project instructions require a separate explicit request for `git commit`.

```python
@dataclass(frozen=True)
class DataAudit:
    rows_in: int
    rows_out: int
    duplicate_rows: int
    missing_intervals: int
    first_timestamp: pd.Timestamp
    last_timestamp: pd.Timestamp

def normalize_ohlc(df: pd.DataFrame) -> tuple[pd.DataFrame, DataAudit]:
    required = {"date", "open", "high", "low", "close"}
    missing = required.difference(df.columns)
    if missing:
        raise ValueError(f"missing columns: {sorted(missing)}")
    data = df[["date", "open", "high", "low", "close"]].copy()
    data["date"] = pd.to_datetime(data["date"], utc=True, errors="coerce")
    for name in ("open", "high", "low", "close"):
        data[name] = pd.to_numeric(data[name], errors="coerce")
    if data.isna().any().any() or not np.isfinite(data[["open", "high", "low", "close"]]).all().all():
        raise ValueError("non-finite OHLC data")
    duplicate_rows = int(data.duplicated("date", keep="last").sum())
    data = data.drop_duplicates("date", keep="last").sort_values("date").reset_index(drop=True)
    invalid = (data["high"] < data[["open", "close", "low"]].max(axis=1)) | (data["low"] > data[["open", "close", "high"]].min(axis=1))
    if invalid.any():
        raise ValueError(f"invalid OHLC rows: {invalid[invalid].index.tolist()}")
    deltas = data["date"].diff().dropna()
    missing_intervals = int(((deltas / pd.Timedelta(minutes=5)).round() - 1).clip(lower=0).sum())
    audit = DataAudit(len(df), len(data), duplicate_rows, missing_intervals, data.iloc[0]["date"], data.iloc[-1]["date"])
    return data, audit
```

Treat gaps as audited source-session gaps rather than synthesizing candles. Reject empty input explicitly before accessing the first/last row.

```python
@dataclass(frozen=True)
class PreparedRange:
    input_bars: pd.DataFrame
    evaluation: pd.DataFrame
    evaluation_start: pd.Timestamp
    evaluation_end: pd.Timestamp

def add_grid_step(df, atr_bars=14, atr_multiplier=0.35, min_step=0.60, max_step=2.50):
    data = df.copy()
    current_atr = atr(data["high"], data["low"], data["close"], window=atr_bars)
    data["atr"] = current_atr.shift(1)
    data["grid_step"] = (data["atr"] * atr_multiplier).clip(lower=min_step, upper=max_step)
    return data

def select_latest_days(df, days=60, warmup_bars=20):
    end = df["date"].max()
    start = end - pd.Timedelta(days=days)
    evaluation_mask = (df["date"] >= start) & (df["date"] <= end)
    first = int(df.index[evaluation_mask][0])
    evaluation = df.loc[evaluation_mask].reset_index(drop=True)
    input_bars = df.iloc[max(0, first - warmup_bars):].reset_index(drop=True)
    return PreparedRange(input_bars, evaluation, evaluation.iloc[0]["date"], evaluation.iloc[-1]["date"])
```

- [ ] **Step 5: Implement continuous monotonic-segment event traversal**

```python
def path_nodes(row: pd.Series, path_mode: str) -> tuple[float, ...]:
    if path_mode == "OHLC":
        return float(row.open), float(row.high), float(row.low), float(row.close)
    if path_mode == "OLHC":
        return float(row.open), float(row.low), float(row.high), float(row.close)
    raise ValueError(f"unsupported path mode: {path_mode}")

def fill_price(mid: float, order_side: int, spread: float) -> float:
    return mid + order_side * spread / 2.0

def layer_lots(layer: int, config: GridConfig) -> float:
    return round(config.base_lot + (layer - 1) * config.lot_increment, 2)
```

For each monotonic segment, repeatedly find the nearest eligible crossed grid level in travel direction, advance the current mid to that level, process the event, recompute eligible levels, and continue until the segment endpoint. A falling segment can add Buy layers only; a rising segment can add Sell layers only. Open each grid order at the crossed mid plus/minus half spread. At the first evaluable node with no positions and no controls blocking entry, open Buy then Sell, using distinct tickets and one shared cycle id.

Assign the bar open to `bar_time`, the first extreme to `bar_time + 100 seconds`, the second extreme to `bar_time + 200 seconds`, and the close to `bar_time + 300 seconds`. Interpolate the timestamp of every crossed price linearly by distance within its monotonic segment. Zero-distance segments consume their endpoint time without generating a duplicate crossing. This synthetic clock is used only to make event ordering and the 30-second cooldown deterministic; document that it is not tick timing.

```python
def position_unrealized(position: Position, mid: float, spread: float, usc_per_price_lot: float) -> float:
    exit_fill = fill_price(mid, -position.side, spread)
    return position.side * (exit_fill - position.entry_fill) * position.lots * usc_per_price_lot

def account_equity(balance: float, positions: list[Position], mid: float, config: GridConfig) -> float:
    return balance + sum(position_unrealized(p, mid, config.spread, config.usc_per_price_lot) for p in positions)
```

Every open/close event records timestamp, bar index, path node, mid, fill, ticket, cycle id, kind, side, layer, lots, balance, equity, grid step, and reason. A close trade additionally records entry/exit fill, realized PnL, holding seconds, and close group id.

For every monotonic segment, basket PnL is affine in mid while the position set is unchanged. Solve the next target price from the aggregate signed lots and entry constants, accept it only when it lies strictly ahead and within the segment, and compare it with the next grid threshold. At equal prices, use the approved event priority. Close orders at adverse-side fills, update balance with each ticket's USC PnL, assign one close group id, remove positions atomically, and write equity after the entire group. A global close sets `cooldown_until = event_time + 30 seconds`; direction close does not delay management of the surviving side.

After a direction basket closes, immediately re-evaluate hedge-kind positions before allowing another event. If keeping a hedge would make absolute net exposure larger than it would be with that hedge removed, close it in the same timestamp group with reason `orphan_hedge_cleanup`. This prevents a hedge from becoming an unowned directional position.

- [ ] **Step 4: Implement hedge definitions and lifecycle**

```python
def exposure(positions: list[Position]) -> tuple[float, float]:
    net = round(sum(p.side * p.lots for p in positions), 8)
    gross = round(sum(abs(p.lots) for p in positions), 8)
    return net, gross

def floored_lots(raw: float, step: float) -> float:
    return float(Decimal(str(raw)) // Decimal(str(step)) * Decimal(str(step)))
```

At a price node, compute floating loss as `max(0, balance - equity)`, including existing hedges. When both trigger inequalities hold and no hedge already opposes the current net side, open one hedge ticket opposite the net side for `min(abs(net), floor(abs(net) * 0.60, 0.01))`. Record pre/post net and gross lots. Pause additional grid layers on the pre-hedge net-exposure side. When floating loss becomes at most 0.75% of current equity, close all hedge-kind tickets as one unlock group and resume both grid sides after recalculating state. Do not loop into a second hedge at the same price node.

Do not defer loss, unlock, or drawdown checks to the four OHLC nodes. While the position set is unchanged, equity and floating PnL are affine in mid, so solve candidate prices for the 1.5% hedge loss boundary, 0.75% unlock boundary, and 20% peak-equity drawdown boundary. Add valid ahead-of-travel candidates to the same nearest-event selection used for basket targets and grid levels. When multiple conditions share a candidate price, apply the documented priority and recompute all candidates after the winning event changes state.

```python
def reconcile_result(result: BacktestResult, initial_balance: float) -> list[str]:
    errors = []
    closed = float(result.trades["pnl_usc"].sum()) if len(result.trades) else 0.0
    open_pnl = float(result.final_positions["unrealized_pnl_usc"].sum()) if len(result.final_positions) else 0.0
    final_equity = float(result.equity.iloc[-1]["equity"])
    if not math.isclose(initial_balance + closed + open_pnl, final_equity, abs_tol=1e-6):
        errors.append("final equity does not reconcile")
    if (result.events.query("kind == 'grid'").groupby(["cycle_id", "side"])["layer"].max() > 9).any():
        errors.append("grid layer cap exceeded")
    return errors
```
