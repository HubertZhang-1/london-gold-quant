## 三、黄金与实际利率/美元的量化回归（研究验证）

来源：Siebert 财经博客《Gold, Real Yields, and the Dollar—No Magic, Just Math》（[链接](https://blog.siebert.com/gold-real-yields-and-the-dollar-no-magic-just-math)）

回归模型：`Gold Ret = α + β1·ΔRealYield + β2·DollarRet + β3·VIXRet + ε`
- **调整 R² = 0.3166**（三个因子解释约 1/3 黄金波动）
- **实际利率、美元高度显著（p 值极低，***）；VIX 不显著**
- **系数**：实际利率每下行 1 点 → 黄金月度约 +6%；美元指数每跌 1% → 黄金约 +0.85%
- **结论**：黄金核心驱动是**实际利率（TIPS）与美元**；VIX 仅在危机时相关。其余 2/3 是噪声（心理、央行购金、亚洲需求）。

## 四、国信证券：CFTC 持仓五因子投票模型（黄金择时）（[链接](http://stock.finance.sina.com.cn/stock/go.php/vReport_Show/kind/macro/rptid/837594496807/index.phtml)）

- 五类参与者（生产商、掉期商、管理基金、其他报告商、非报告商），构建 5 个独立因子：
  1. 投机多头占比（管理基金情绪）
  2. 商业空头交易商占比（产业锁价）
  3. 前四大空头集中度
  4. 商业净多持仓（套保是否恐慌）
  5. 其他报告商多头变化（半机构动量）
- 五因子平均绝对相关系数 **0.18**（彼此独立）；2/5 投票规则。
- **回测（2012-2026，约 14.6 年）**：夏普 **1.19**、年化 **14.7%**、累计 **657%**、最大回撤 **-18.5%**、持仓率 54%；同期买入持有年化 7.9%、最大回撤 -41.4%。
- **训练(2012-18) vs 测试(2019-26) 夏普 1.22 vs 1.25 —— 样本外未崩塌**。
- 70 笔中 54 盈利，**胜率 77%、赔率 3.49**，年均 ~5 次，13 个完整年份仅 2022 平平。
- 移植到白银（零调参）仍有效（夏普 0.56、累计 409%）。
- 最新信号（2026-07-07 报告周）：**空仓**（1/5 票）。

## 五、东证期货：黄金择时因子及多周期合成（商品基本面量化框架系列二）（[链接](https://www.sohu.com/a/874371417_122014422)）

**三维度四子策略框架**：
- **宏观维度**：TIPS 通胀债对黄金定价、原油/美元/VIX 高阶关系 → 长周期择时（样本外夏普 0.81）
- **中观维度**：CFTC 持仓 400+ 因子 → 短周期择时（样本外夏普 **1.03**）
- **微观维度**：黄金量价识别市场环境，趋势性分四象限，合成趋势度调仓（最大回撤 21.38% → 9.51%）

**多周期合成后（只做多 / 多空 / 静态持有）**：
- 年化收益：**14.72% / 16.63% / 13.94%**
- 年化波动：**9.87% / 11.59% / 15.18%**
- 年化夏普：**1.49 / 1.43 / 0.92**
- 最大回撤：**12.13% / 12.13% / 21.38%**
- Calmar：**1.21 / 1.37 / 0.65**

**结论**：多周期合成的只做多/多空策略 2020 至今稳定跑赢静态持有。
