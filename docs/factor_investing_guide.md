## 二、主要因子家族

### 价值因子 Value
- 定义: 买入价格低于内在价值的股票
- 指标: Book-to-Market, Earnings-to-Price, Sales-to-Price
- 起源: Fama-French三因子(1993)
- A股: EP/CP有效性较高; BP行业暴露大
- 注意: 价值陷阱需质量因子过滤

### 动量因子 Momentum
- 定义: 过去表现好的股票未来继续表现好
- 指标: 过去12个月收益(剔除近1月)
- 起源: Jegadeesh & Titman (1993), Carhart四因子
- A股: 短期反转强于动量; 中期动量需3-6个月持有期
- 注意: 动量崩溃风险(市场剧烈反转时)

### 质量因子 Quality
- 定义: 盈利能力高、财务稳健的公司
- 指标: ROE, 毛利率, 资产负债率, 应计利润
- 起源: Novy-Marx (2013), Asness QMJ因子(2014)
- A股: ROE因子长期有效; 毛利率在消费行业显著
- 注意: 需平衡质量和估值水平

### 规模因子 Size
- 定义: 小市值公司回报更高
- 指标: 总市值、流通市值
- 起源: Banz (1981), Fama-French三因子
- A股: 小市值效应显著但近年减弱
- 注意: 流动性差、交易成本高

### 低波动因子 Low Volatility
- 定义: 低波动股票风险调整后收益更高
- 指标: 过去3-5年日/周波动率、Beta
- 起源: Ang et al. (2006)
- A股: 有效但需控制行业暴露

### 红利因子 Dividend
- 定义: 高股息率股票长期表现更好
- 指标: 股息率、股息增长率
- 起源: 狗股策略(Dogs of the Dow)
- A股: 震荡市表现突出
- 注意: 高股息可能反映股价下跌

### 成长因子 Growth
- 定义: 高成长公司收益和价格表现
- 指标: 营收增长率、净利润增长率
- A股: 波动大; 与价值因子负相关
- 注意: 成长陷阱(预期已被定价)

### 反转因子 Reversal
- 定义: 短期涨过头会回调，跌过头会反弹
- 指标: 过去1周/1个月收益率
- 起源: Jegadeesh (1990)
- A股: 短期反转效应非常显著
- 注意: 交易成本敏感

## 三、多因子模型演进

CAPM (Sharpe, 1964)
  -> Fama-French 3因子(1993): 市场+规模+价值
    -> Carhart 4因子(1997): +动量
    -> Fama-French 5因子(2015): +盈利+投资
    -> Asness 4因子(2014): 价值+动量+质量+规模
  -> Hou-Xue-Zhang 4因子(2015): 市场+规模+盈利+投资

主流多因子框架:
- Fama-French 3: 市场/规模/价值 (学术基准)
- Carhart 4: +动量
- Fama-French 5: +盈利/投资
- Asness QMJ: 价值/动量/质量 (实战常用)
- Barra USE4: 10+风格因子 (机构标准)

## 四、因子构建方法论

### 构建步骤
1. 因子定义 - 经济逻辑和计算方式
2. 数据清洗 - 去极值、标准化、行业中性化
3. 分层回测 - 按因子值分5/10组，观察单调性
4. 多空组合 - 做多最高组做空最低组
5. 风险调整 - 夏普比率、信息比率、最大回撤
6. 显著性检验 - t统计量、Fama-MacBeth回归

### 因子处理流程
原始因子值 -> 去极值(MAD/百分位数) -> 标准化(Z-score) -> 行业中性化 -> 市值中性化 -> 正交化 -> 最终因子

### IC分析
- Rank IC: 因子值与下期收益的秩相关系数
- IC均值: 因子预测能力稳定性
- IC标准差: 预测能力波动性
- IR(IC/σ_IC): 因子整体表现衡量标准

## 五、因子加权与组合

### 加权方式
- 等权: 每个因子权重相同
- IC加权: 按IC历史表现加权
- IC_IR加权: IC均值/IC标准差加权
- 优化加权: 最大化组合IC/夏普
- 机器学习: 非线性因子组合

### 组合约束
- 个股权重上限(如5%)
- 行业偏离度控制
- 换手率约束
- Beta中性

### 绩效指标
- 夏普比率: (Rp-Rf)/σp
- 信息比率: α/σ(ε)
- 最大回撤: max(Peak-Trough)
- Calmar比率: 年化收益/最大回撤

## 六、A股因子实战

| 因子 | A股有效性 | 持有期 | 注意事项 |
|:----:|:--------:|:-----:|---------|
| 价值 | 中等 | 12月 | 需过滤ST和财务造假 |
| 动量 | 中等偏弱 | 3-6月 | 短期反转效应强 |
| 质量 | 强 | 12月 | ROE因子突出 |
| 规模 | 强(减弱中) | 6月 | 注册制影响 |
| 低波 | 中等 | 12月 | 控制行业暴露 |
| 红利 | 强 | 12月 | 震荡市表现好 |
| 成长 | 中等 | 6月 | 波动大 |
| 反转 | 强 | 1月 | 交易成本敏感 |

### A股实战注意事项
1. 交易成本: 印花税+佣金约单边0.1%
2. T+1制度: 日内策略受限
3. 涨跌停板: 极端行情执行困难
4. 财报季: 4月/8月/10月, 因子表现可能异常
5. 政策风险: 行业政策可能导致因子短期失效
6. ST/*ST股票需要排除
