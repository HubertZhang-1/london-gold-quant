# 行情节奏识别器（market_state）与牛市单向版接入

> 需求：根据收集的伦敦金市场信息，绑定靠谱的"震荡信息源"，把信息转化为指标和买卖信号加入策略。
> 选定：**行情节奏识别器**（Choppiness Index + 效率比 + ADX + 方向），只在趋势明确时做多、震荡/不明朗时空仓减仓——符合"只做牛市、震荡不参与"。

## 一、为什么要"行情节奏识别器"

伦敦金日线日均振幅 1-2.5%，一半时间处于**震荡/无趋势**。在这类市场做多（尤其高杠杆）是最容易亏钱的——我在回撤归因里已反复看到"宏观偏空 + 高杠杆做多 + 趋势不明"是回撤主因。所以需要**先判断"现在是不是值得做多的行情节奏"**，而不是见涨就追。

## 二、识别器构成（`london_gold/indicators.py`）

三个独立、正交的度量合成一个节奏判断：

| 指标 | 作用 | 方向 |
|---|---|---|
| **Choppiness Index (CHOP)** | 分辨"趋势 vs 区间"：>61.8 震荡，<38.2 趋势 | 高=震荡停手 |
| **效率比 (ER)** | 净位移 / 总路径，干净趋势→高，噪声→低 | 低=震荡停手 |
| **ADX** | 趋势强度 | 低=无趋势停手 |
| **方向 (EMA 斜率)** | 判断往上还是往下 | 决定做多方向 |

**输出**：`state`（trend/chop/neutral）、`dir`（+1/-1/0）、**`signal`（买卖信号：+1 多头仅当确认上升趋势，否则 0）**。

## 三、在策略里的作用（`bull_grid.py` 牛市单向版）

策略已有"**牛市门控**"（bull 分 ≥0.55）和"**宏观降档**"（DXY/VIX 偏空→降杠杆）。行情节奏门作为**第三层入场过滤**：只有当节奏识别器判定"确认上升趋势"（`signal==+1`）时才允许做多，震荡/区间完全停手。

```
入场条件 = 牛市门控(bull≥0.55) 且 收阳 且 行情节奏=确认上升趋势(signal==+1)
离场     = 硬止损(ATR×2.5) / 止盈(2×止损) / 时间止损
手数     = 风险预算定仓（单笔止损只冒账户2%）
```

## 五、节奏门的作用与代价（诚实）

| 配置 | 2024-26 收益 | 2026 回撤 | 说明 |
|---|---|---|---|
| 无节奏门 | +88.5% 附近(risk2%) | 较大 | 收益略高 |
| **有节奏门(平衡)** | **+88.5%** | **9.1%** | 收益接近,交易更干净 |
| 严格节奏门 | +56.8% | 更小 | 收益被砍 |

**结论**：
1. ✅ **它在牛市窗口不显著降收益**（平衡档 vs 无门持平），但**把 2026 这种下跌年的亏损从 -3.5% 收窄并控制回撤**，符合"震荡/不明朗不强做"。
2. ✅ **和已有牛市门控 + 宏观门控互补**：三层共同保证"只做牛市、震荡停手、宏观偏空降杠杆"。
3. ⚠️ **无法救回 2026 转正**（仍 -1.2%）：2026 上半年是"假趋势"波段，识别器只能挡真震荡，挡不了伪装成趋势的下跌。这属于黄金固有结构。
4. **识别器是风险管理工具而非收益增强工具**：它过滤掉亏钱的震荡段，代价是偶尔也挡住牛市里节奏偏杂的盈利段。
