# 日线级别高杠杆测试：能否放大杠杆上限

> 动机：1h 上 10 倍必爆仓（黄金日内波动大）。本测试验证**日线级别**（波动/跳空更小）能否承载更高杠杆，尤其 10 倍。
> 数据：`data/XAUUSD_1d.csv`（1h 聚合到日线，2004-2026，5718 根）。

## 一、先看日线真实波动

| 年份 | 日均振幅 | | 年份 | 日均振幅 |
|---|---|---|---|---|
| 2018 | 0.97% | | 2023 | 1.23% |
| 2019 | 1.10% | | 2024 | 1.39% |
| 2020 | 1.74% | | 2025 | 1.63% |
| 2021 | 1.33% | | **2026** | **2.48%** |
| 2022 | 1.43% | | | |

**关键**：黄金日线日均振幅 **1%-2.5%**。10 倍杠杆下，一天的正常波动 = 10-25% 权益波动（若满仓）——所以日线的"波动小"并没有想象中那么小。

## 三、核心结论（诚实）

### ✅ 日线确实提高了杠杆上限
- **2025 在日线 10x 达 +222%**（1h 上 10x 必爆仓）——日线过滤掉了 1h 的震荡噪声，干净单边趋势下 10 倍可行。
- **2024 日线 10x 也能 +33%~+90%**（1h 上 2024 反而 -15.9%）。

### ⚠️ 但日线高杠杆不稳定、对参数极其敏感
1. **2020/2026 日线高杠杆仍爆仓**（-100%）——这两年日线有大回调 / 高波动（2026 日振幅 2.48%，3 倍就爆）。
2. **严格过滤只在个别年份有效**——2025 用宽松门槛好 +222%、2024 用严格门槛好 +90%，**不同年份对同一过滤器的反应相反**。这说明日线 10x 对参数极度敏感，任何单调过滤都无法普适。
3. **2026 日线任何杠杆都爆仓**（-100%）——高波动年（日振幅 2.48%±）根本不可用高杠杆。

## 四、判断

**日线能放大杠杆上限，但只适用于"干净单边趋势 + 适度波动"的组合（2025 是典范），无法作为普适的高杠杆策略。**

真正的挑战不是杠杆倍数，而是**能否提前识别出 2025 这类"可以上 10 倍"的年份**——这需要极其精细的择时（趋势持续性 + 波动率在健康区间 + 无深度回调），目前无法可靠地做。

## 五、使用建议

| 场景 | 建议 |
|---|---|
| **只做 2025 型**（干净单边趋势、波动1.6%） | 日线 10x 可行（+222%） |
| **2024 型**（趋势但年份内震荡） | 日线 3-5x（+15%~+90%），或 1h 3x |
| **2026 型**（高波动2.5%） | **不可用高杠杆**，1-2x 为限 |
| **实盘稳健** | **1h 2-3x**（+28%~+42%），日线只在确认干净趋势年放大到 5-10x |

**核心提醒**：黄金日线平均日振幅 1-2.5%，实际并不小。日线 10 倍的高收益（2025 +222%）是"确认趋势正确 + 波动适中"的幸运组合，**绝不能常态化预期**。高杠杆的核心风险（回调 vs 熔断）在日线依然存在，只是门槛略高。
